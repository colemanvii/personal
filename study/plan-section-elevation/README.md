# Plan · Section · Elevation

Three working studies of an artist's website, each a different idea:

| Folder | Role | Idea |
|---|---|---|
| `plan/` | Public experience | A showing is a curated way in: entrance, checklist, one work at a time with a wall label. If you stay on a work, its label opens onto related work. *Sit* turns the showing by itself. All work is always one step away. |
| `section/` | Archive | Disciplines as layers across time. Cut through any year. Every fact is marked verified, inferred, study label, reading or missing, with its source. Undated work sits apart. *What we know* maps the gaps. |
| `elevation/` | Private workspace | A 12 ft × 7 ft wall drawn as an elevation. Paintings hang at recorded sizes. The wall is finite, the library holds everything else, and snapshots are dated and can be proposed for the public site. Saved in this browser only. |

`index.html` is the entry page and the system map (Tangerine · TABLET · Notion · website).
It has no doctype because it is also published as a Claude artifact.

Nothing here is deployed. `site/` and the earlier `study/next-chapter/` are untouched.
`media` is a link to `../next-chapter/media`, so there is one set of web images.

## Data

`data/records.js` is generated by `tools/build_records.py` from the live site's own files
(`site/index/index.html`, `site/index/paintings-archive.js`, `site/paintings/index.html`) via
`study/next-chapter/media/catalogue.js`. Each field carries a status and a source:

- `v` verified: stated for this work in a named source
- `i` inferred: from a source, but not stated for this work (most dates are the project's year)
- `p` study label: a working name given because none is recorded
- `x` reading: Claude's interpretation of the images (motifs), unconfirmed
- `m` missing: not recorded anywhere available

No dates, provenance, collectors or relationships are invented.

```sh
python3 study/plan-section-elevation/tools/build_records.py
python3 -m http.server 4190 --bind 127.0.0.1 --directory study/plan-section-elevation
```
