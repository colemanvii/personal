# Cole Calfee Site — Review Brief

Repository: colemanvii/personal

## Goal
This is a small static personal archive for Cole Calfee — photography, design, artwork, and other creative work.

It should feel:
- simple
- sophisticated
- personal
- editorial
- restrained
- slightly technical / cyber in precision, not in visual effects
- warm rather than sterile
- like a living archive, not an agency portfolio

## Visual direction
Key references / principles:
- Brooks Reitz-level simplicity
- old art-book / monograph restraint
- Haven-style interface precision
- warm off-white field
- black ink
- surgical use of deep red
- tiny mono metadata
- serif hierarchy
- asymmetric image placement
- no rounded cards
- no gradients
- no trendy animation
- no generic luxury/creative-agency portfolio language

## Site structure
- /
- /art/
- /design/
- /photos/
- /index/
- /info/

There is also an older /work/ route that may be removed or redirected.

## Core concept
The site is a record of an eye.

Instagram can be personal and chaotic.
The website should be the stable archive underneath:
- show the work
- make it easy to understand the range
- make it easy to contact Cole
- eventually support shop / prints

## Review request
Please review the current HTML/CSS/JS as a senior design engineer + art director.

Do not redesign from scratch.

Please identify:
1. HTML / semantic issues
2. CSS architecture problems
3. responsive problems
4. routing inconsistencies
5. accessibility problems
6. anything that feels generic, overdesigned, or too portfolio-template-like
7. anything that weakens the "quiet living archive" concept
8. the five highest-leverage improvements

Be critical and specific.

If suggesting code changes, explain why they improve the experience before rewriting anything.
