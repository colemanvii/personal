# Artwork registry

[`artwork-registry.csv`](artwork-registry.csv) — the working index of all 80 artworks
(generated from `registry_data.py`; edit the Python and re-run, so IDs stay stable).

- IDs `WO-<edition>-<nn>` are permanent. A cut piece keeps its ID with status `cut`; its
  replacement gets the next free number.
- This is a curatorial plan, not 80 prompts. Subjects and titles are provisional and are
  expected to change on site and at the drawing table — especially the 1/40, where the
  station fixes *where* the drawing is made and the land decides *what* it is.
- Current balance: 19 dense · 35 mid · 26 spare.
- `hashes.csv` will record SHA-256 for every raw capture, master and export.
